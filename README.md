# বগুড়া ইসলামিক ক্যালেন্ডার ও নামাজের সময়সূচি

বগুড়া জেলার জন্য সম্পূর্ণ বাংলা ভাষায় ইসলামিক ক্যালেন্ডার ও নামাজের সময়সূচি।



## যা আছে

- আজকের পাঁচ ওয়াক্ত নামাজ — লাইভ ঘড়ি, চলমান ও পরবর্তী ওয়াক্তের কাউন্টডাউনসহ
- মাসিক সময়সূচি (নভেম্বর ২০২৬–ডিসেম্বর ২০২৭, ব্রাউজারেই গণনা হয়)
- ইসলামি দিবস ও ঘটনা — ক্যালেন্ডার গ্রিড ও তালিকা ভিউ
- রমাদান ২০২৭ কাউন্টডাউন ও ৩০ দিনের সেহরি-ইফতার টেবিল
- লাইট / ডার্ক মোড, প্রিন্ট স্টাইল, শেয়ার বাটন

## গণনা পদ্ধতি

- অবস্থান: বগুড়া শহর (২৪.৮৫° উত্তর, ৮৯.৩৭° পূর্ব), সময় অঞ্চল Asia/Dhaka (UTC+৬)
- পদ্ধতি: University of Islamic Sciences, Karachi (ফজর/এশা ১৮°), আসর হানাফি মাযহাব
- সময়সূচি ব্রাউজারেই গণনা হয় — কোনো API বা ব্যাকএন্ড লাগে না
- হিজরি তারিখের ডিফল্ট: বাংলাদেশ (সৌদির তুলনায় ১ দিন পরে); "সৌদি হিসাব" বেছে নেওয়া যায়
- রমাদান ১৪৪৮: সৌদি হিসাবে ৮ ফেব্রুয়ারি ২০২৭, বাংলাদেশে সম্ভাব্য ৯ ফেব্রুয়ারি ২০২৭ — চাঁদ দেখার ওপর নির্ভর করে তারিখ ১ দিন আগে-পরে হতে পারে

এটি গণনাভিত্তিক সময়; স্থানীয় মসজিদের জামাতের সময় ভিন্ন হতে পারে।
